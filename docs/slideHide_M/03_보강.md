# slideHide Method 보강 기록

## 공통 헬퍼 createBasicSlideHide 입력 컴포넌트 추가 + setReadOnly / setDisabled 자식 적용 실측 (2026-09-30, 엔진 R1669)

### 헬퍼 변경 (`cm/gcc/common.xml` createBasicSlideHide 만 수정, +7줄)

- 기존 자식(토글 바 group, textbox "Favorite" / "- Fruits" / "- Fish") **뒤에** `xf:input` 2개를 `.main`(slideHideMain DOM) 부모로 dynamicCreate.
  - input1: `initValue="Apple"` (복사 가능 확인용), input2: 빈값 (입력 확인용)
  - style: `display:block;margin:4px 0px 0px 18px;width:72px;height:22px;` (95x182 안에 들어감)
  - id 는 빈값(자동 부여 `mf_wq_uuid_N`) - getGenerator 로 slideHide 2개 생성 시 중복 alert 방지
- 인라인 예외 샘플(getID / getOriginalID / getPosition / setPosition)은 수정하지 않음.

### 렌더 확인 (헬퍼 사용 31건)

- 31건 모두 `.main` 자식 6개(group 1, textbox 3, input 2), 첫 `.w2textbox` = "Favorite", 열림 상태에서 input 2개가 slideHide 영역 안에 표시됨.
- 토글 바 클릭 open→hide→open 정상, Target 재생성 후 자식 6개 유지, getGenerator 는 slideHide 2개, console error / pageerror / dialog 0건.

### setReadOnly(true) / setDisabled(true) 자식 적용 실측

| 구성 | 자식 parentControl | readOnly: 자식 getReadOnly / DOM readOnly / 키 입력 | disabled: 자식 getDisabled / DOM disabled / 키 입력 |
|---|---|---|---|
| slideHide 헬퍼(동적, `.main` DOM 부모) | null (childControlList 0) | false / false / 입력됨 | false / false / 입력됨 |
| slideHide 정적 마크업 | mf_sh1 (childControlList 4) | false / false / 입력됨 | false / false / 입력됨 |
| group 정적 마크업 | mf_g1 | true / true / 차단 | true / true / 차단 |
| group 동적(컴포넌트 부모) | gcmp | true / true / 차단 | true / true / 차단 |
| group 동적(render DOM 부모) | null | false / false / 입력됨 | false / false / 입력됨 |

- slideHide 자신의 getReadOnly() / getDisabled() 는 true 로 설정됨. 자식에게만 전파되지 않음.

### 판정

- 동적 헬퍼 구성만으로는 판정할 수 없음: `.main` DOM 부모로 생성하면 parentControl 이 null 이 되어 group 도 전파하지 않는다(샘플 구성의 한계).
- **정적 마크업**에서는 자식이 slideHide 에 등록(parentControl=mf_sh1)되어 있는데도 전파되지 않는다. 같은 조건의 group 은 전파한다. 따라서 **엔진 결함 후보**이며, scrollView WAEA-1316 과 같은 구조다.
- 근거: `uiplugin/slideHide/slideHide.js` 에 setReadOnly / setDisabled 정의가 없어 `control/xfControl.js` L2143 setDisabled / L2205 setReadOnly(자기 속성만 설정)를 그대로 쓴다. group 은 `group.js` L1828 setDisabled(childControlList 순회), L2292 setReadOnly(invoke)로 전파한다. `xfControl.invoke` L3154 의 executableComponents 에도 slideHide 가 없다.
- 부수 관찰: Target 재생성(remove) 뒤에도 이전 동적 자식 컴포넌트 객체가 레지스트리에 남는다(DOM 은 제거됨). id 가 자동 부여되어 중복 오류는 없다.

**검증 수단**

다운로드된 xlsx 로는 excelCellType 차이를 확인할 수 없다(서버가 표시 문자열을 숫자로 재파싱하고 displayFormat 을 numFmt 으로 그대로 적용). 따라서
`HTMLFormElement.prototype.submit` / `XMLHttpRequest.prototype.send` 를 **메소드 호출 구간에만** 감싸 `input[name=xmlValue]` 의 전송 XML 을 캡처하고
(실제 다운로드는 그대로 통과), 그 안의 `hashkey='style'` 에 직렬화된 GridView XML 에서 `<w2:footer>` / Footer `<w2:column>` 의 `excelCellType` 을 파싱해 판정한다.

**전송 XML 구조 (실측)**

```
<vector result='1'><data vectorkey='0'><hashtable>
  <data hashkey='style'>  <!-- 직렬화된 GridView XML 전체. excelCellType 은 여기에만 실린다 -->
    ... <w2:footer style="" id="footer1" excelCellType="number">
          <w2:row style="" id="row3">
            <w2:column ... id="footer_col1" value="8002.3" excelCellType="text"/> x4
          </w2:row>
        </w2:footer> ...
  </data>
  <data hashkey='footer_data'><array><![CDATA[["8002.3","8002.3","8002.3","8002.3"]]]></array></data>  <!-- 값만, 타입 없음 -->
  <data hashkey='useDataFormat' value='true'/>
  ... (총 100여개 hashkey)
</hashtable></data></vector>
```

**케이스별 실측 출력**

| con_excelCellType (footer) | con_columnExcelCellType | par_useDataFormat | 전송 XML footer / footer column | 전송 useDataFormat |
|---|---|---|---|---|
| text | date | true | `text` / `date` | `true` |
| number | date | true | `number` / `date` | `true` |
| bigDecimal | date | true | `bigDecimal` / `date` | `true` |
| date | text | true | `date` / `text` | `true` |
| number | text | false | `number` / `text` | `false` |
| (미설정) | (미설정) | true | 속성 자체 미출력 (미설정) | `true` |

결과창 출력(실측, footer=number / footer column=text / useDataFormat=true)

```
[1] 설정값 footer=number / footer column=text -> 전송 XML : footer=number / footer column=text
[2] text 설정 여부 : false
[3] number 설정 여부 : true / 전송 XML 의 footer excelCellType : number (Excel 표시 형식 : 숫자)
[4] bigDecimal 설정 여부 : false
[5] date 설정 여부 : false
[6] 전송 useDataFormat : true / 전송 XML 의 footer column excelCellType : text
```

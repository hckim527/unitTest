### 구성 방식 (정적 배치 확정 근거)

- 배포 엔진(R1641)에 `nav` uiplugin 미탑재. 엔진 번들 내 해당 문자열은 `WebSquare.uiplugin.group.html5={article:"div",aside:"div",nav:"div",...}` 뿐이며, 이는 `group.toHTML()` 의 **IE6/7/8 전용 tagname 폴백표**로 지원 근거가 아님. `controlFactory.createControlHash` 에도 미등록.
  - ※ `_websquare_/uiplugin/` 폴더 목록은 지연 로딩 플러그인만 담으므로(span/button/input 도 없음) 미탑재 판단 근거가 되지 않는다.
- `$p.dynamicCreate` 사용 불가 (동일 계열 `article`/`aside`/`section` 으로 실측 확정, `nav` 동일):
  - `dynamicCreate(id,"nav",'<nav…>',parent)` → `Cannot read properties of undefined (reading 'then') at d.createControl`. XML 문자열을 주면 2번째 인자 pluginName 은 무시되고 노드 localName 으로 플러그인이 결정됨.
  - config `/WebSquare/dynamicCreate/parseChild/@value="true"` 강제 → `t.appendTo is not a function` 로 여전히 실패.
  - `dynamicCreate(id,"group",'<xf:group tagname="nav">')` → 렌더는 되나 `class="w2group "` 기본 클래스가 붙어 본 API 의 `@spec`(기본 클래스 미추가)과 정면 배치 → 부적합.
- 정적 `<nav>` 는 raw HTML pass-through 로 렌더되어 class/id 가 가이드와 일치 → DOM(`document.querySelector`) 기준 검증 유효 (MCP 실측으로 확인).
- 따라서 UT_01 §7 정적 컴포넌트 배치 규칙 적용 (`wf_body_sample` 삭제, `grp_sample > grp_comp` 직접 배치, `comp_init`/`Target 재생성` 버튼 없음).
- `cm/gcc/common.xml`, `websquare/config.xml` 무수정. class 검증용 CSS 는 공용 `css/tc.css:45-46` 의 `.oddClass`(border 1px solid red) / `.evenClass`(border-radius 15px) 재사용(샘플 자체 style 블럭 없음).

**구성 방식 / 판단 근거**

- 배포 엔진(R1641)에 `nav` uiplugin 미탑재. 번들의 `uiplugin.group.html5={...nav:"div"...}` 는 `group.toHTML()` 의 IE6/7/8 tagname 폴백표라 지원 근거가 아니며 `controlFactory.createControlHash` 에도 미등록 → `$p.dynamicCreate` 사용 불가(확정 전제). 따라서 **정적 `<nav>` 3개 선언**(id 설정 / id 미설정 / 예약어 id) 방식으로 구성.
- `@spec` Scope 미적용 입증은 **정적 선언끼리 대비**해야 성립(동적 생성 컴포넌트는 원래 `mf_` 접두사가 붙지 않음) → `<nav id="target1">` 정적 vs `<w2:button id="btn_getId">` 정적(`mf_btn_getId`) 로 대비.
- (3) 은 `nav` 이 컴포넌트 객체가 아닌 raw DOM 이므로 "스크립트 접근"을 DOM 조회로 입증. id 미설정본은 자동 부여 id(`wq_uuid_NN`)를 사전에 알 수 없어 지정 id 로 조회 불가함을 대비 출력.
- `cm/gcc/common.xml`, `websquare/config.xml` 무수정.

**엔진 사실 / 제약 (실측)**

- 정적 `<nav>` 는 raw HTML pass-through 로 렌더되어 WebSquare 클래스(`w2group` 등)가 붙지 않고 태그도 유지됨.
- id 미설정 시 자동 부여 id 형식은 `wq_uuid_NN` (WebSquare 컴포넌트의 `mf_wq_uuid_NN` 과 달리 `mf_` 없음).
- **예약어(`style`) 를 id 로 설정해도 JS 오류 0건**, id 는 `style` 그대로 렌더됨. 가이드 `@spec` 이 "오류가 발생할 수 **있습니다**"(가능성) 표현이므로 validation 문구는 원문 유지하고, 실측상 이 계열(raw HTML pass-through)에서는 오류가 발생하지 않음을 기록.

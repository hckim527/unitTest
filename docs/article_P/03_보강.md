### @spec 2 (예약어) 실측 판정

- 속성명 예약어 `style` 을 id 로 설정해도 **오류가 발생하지 않고 정상 렌더**됨(JS 오류 0건, `article[id='style']` 조회 성공).
- 원문이 "오류가 발생할 수 있습니다"(가능성) 이므로 validation 문구는 가이드 원문 유지. 단, 현재 배포 엔진(R1641)에서 `article` 은 uiplugin 이 아닌 **raw HTML pass-through** 이므로 컴포넌트 id 예약어 충돌 경로 자체가 없다 — 즉 이 `@spec` 은 article uiplugin 이 엔진에 반영된 이후에야 재확인 가능하다.

### 참고 — article 동적 생성(dynamicCreate) 실측 (R1641, 2026-09-03)

정적 배치로 최종 확정되었으나, 동적 생성 가능 여부를 실측한 결과를 남긴다.

| 시도 | 호출 형태 | 결과 |
|---|---|---|
| 1 | `$p.dynamicCreate(id, "article", '<article ...>', parent)` | **실패**(반환 undefined). 콘솔: `TypeError: Cannot read properties of undefined (reading 'then') at d.createControl` + `TypeError: Cannot read properties of null (reading 'initAsync') at h.dynamicCreate` |
| 2 | 1번 + 런타임으로 `/WebSquare/dynamicCreate/parseChild/@value="true"` 강제 | 플러그인 조회는 통과(raw tag 경로 진입)하나 **`TypeError: t.appendTo is not a function at h._dynamicCreateAfter`** 로 DOM 미생성 → **config 한 줄로 해결 불가** |
| 3 | `$p.dynamicCreate(id, "group", '<xf:group tagname="article" ...>', parent)` | **성공** — `<article id="probeB" class="w2group ">` 렌더. 단 `w2group` 기본 클래스가 붙어 article 의 class `@spec`("웹스퀘어 기본 클래스 미추가") 과 어긋남 |
| 3-b | 3번에서 id 를 `""` 로 | `<article id="wq_uuid_46">` 자동 부여 |
| 3-c | 3번에서 id 를 예약어 `"style"` 로 | **반환 undefined = 컴포넌트 생성 실패** |
| 4 | `pluginName`만 `"group"`/`"article"` 로 바꾸고 마크업은 `<article>` | 무의미 — XML 문자열을 주면 2번째 인자는 무시되고 태그 localName 으로 플러그인이 결정됨 |

- 동적 생성된 WebSquare 컴포넌트(`group`, `textbox` 등)의 렌더 id 는 **`mf_` Scope 접두사가 붙지 않는다**(`probeD` → `<div id="probeD">`). 즉 `@spec` "Scope 적용없이 그대로 사용" 은 **정적 선언 컴포넌트끼리 대비**해야만 입증 가능하다(정적 `<article id="target1">` vs 정적 `<w2:button id="btn_getId">` → `mf_btn_getId`).
- 서빙 엔진 번들(`javascriptLoader.wq`, 5.3MB) 전문 검색 결과 `article` 문자열은 `WebSquare.uiplugin.group.html5={article:"div",...}` **1건뿐**이며, 이는 **IE6/7/8 전용 tagname 폴백 표**다(`toHTML` 내 `browserCheck.ie && version in 6,7,8` 분기). article uiplugin 미탑재가 재확인됨.

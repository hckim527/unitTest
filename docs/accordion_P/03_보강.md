## accordion_P_accessibility_1.xml

API: `WebSquare.uiplugin.accordion.accessibility`
설명: Accordion 컴포넌트에 웹접근성 지원 기능을 일괄적으로 적용할지 설정합니다.

| API 가이드 항목 | 샘플 validation | 케이스 | 상태 |
|---------------|---------------|------|------|
| @description: Accordion 컴포넌트에 웹접근성 지원 기능을 일괄적으로 적용할지 설정합니다. | description 영역에 반영 | - | OK |
| @propval(true): 웹접근성 지원 기능을 일괄적으로 적용합니다. | (1) "true 설정 시 Accordion 컴포넌트에 웹접근성 지원 기능을 일괄적으로 적용합니다." | con_accessibility=true | OK |
| @propval(true): PanelTitle 영역이 `<a>` + `<span>` 태그로 렌더링 | (2) "true 설정 시 PanelTitle 영역이 'a' + 'span' 태그로 렌더링됩니다." | con_accessibility=true → btn_getRender (panelTitle1_title tagName=A, firstChild SPAN) | OK |
| @propval(true): `<a>` 태그에 role=button, aria-expanded=false 부여 | (3) "true 설정 시 PanelTitle 의 'a' 태그에 role='button', aria-expanded='false' 속성이 부여됩니다." | con_accessibility=true → btn_getRender (role/aria-expanded 출력) | OK |
| @propval(true): titleDivTag 무관 타이틀 tagname=strong | (4) "true 설정 시 titleDivTag 속성값과 관계없이 타이틀의 tagname 이 'strong' 으로 설정됩니다." | con_accessibility=true × con_titleDivTag=true/false → btn_getRender (title label tagName=STRONG) | OK |
| @propval(true): onkeydown 이 PanelTitle(`<a>`)에 바인딩, PanelTitle 포커스 시에만 Enter 동작 | (5) "true 설정 시 키보드 이벤트(onkeydown)가 Panels 전체가 아닌 PanelTitle 요소('a' 태그)에 바인딩되어 PanelTitle 에 포커스가 있을 때만 Enter 키가 동작합니다." | con_accessibility=true → btn_getKeydownTarget + btn_focusTitle 후 Enter / btn_focusPanels 후 Enter (동작 안함) | OK |
| @propval(false): 웹접근성 지원 기능을 일괄 적용하지 않습니다. | (6) "false (default) 설정 시 Accordion 컴포넌트에 웹접근성 지원 기능을 일괄적으로 적용하지 않습니다." | con_accessibility=false | OK |
| @propval(false): PanelTitle 이 `<div>` 태그로 렌더링 | (7) "false (default) 설정 시 PanelTitle 영역이 'div' 태그로 렌더링됩니다." | con_accessibility=false → btn_getRender (panelTitle1_title tagName=DIV) | OK |
| @propval(false): onkeydown 이 패널 전체에서 발생 | (8) "false (default) 설정 시 키보드 이벤트(onkeydown)가 패널 전체에서 발생합니다." | con_accessibility=false → btn_focusPanels 후 Enter | OK |
| 기본값 false (필수여부 N) | (9) "값을 생략하면 기본값 false 로 동작합니다." | con_accessibility=빈값 (allOption) | OK |

### 보강 체크리스트 (_1.xml)
- [x] @description 반영
- [x] @propval(true) 5개 세부 동작 모두 개별 validation
- [x] @propval(false) 3개 세부 동작 모두 개별 validation
- [x] 필수여부 N → 미설정 시 기본값(false) 동작 validation
- [x] titleDivTag 조합으로 strong 강제 적용 검증 가능
- [x] render 확인 / onkeydown 바인딩 / 포커스 버튼 4개로 동작 검증 지원

## accordion_P_accessibility_2.xml

API: `WebSquare.uiplugin.accordion.accessibility`
설명: Accordion 컴포넌트에 웹접근성 지원 기능을 일괄적으로 적용할지 설정합니다. (collapsible/enterKeyPanelToggle/disabledPanels 조합)

| API 가이드 항목 | 샘플 validation | 케이스 | 상태 |
|---------------|---------------|------|------|
| @propval(true): collapsible=false 환경에서 이미 열린 패널 타이틀 재클릭 시 다른 패널 닫힘 → 현재 패널 닫힘 → 다시 열림 | (1) "accessibility=true 이고 collapsible=false 환경에서 이미 열린 패널의 타이틀을 클릭하면 다른 패널이 먼저 닫힌 후 현재 패널이 닫히며, 이후 다시 열리는 동작이 수행됩니다." | con_accessibility=true × con_collapsible=false → panels1 펼친 뒤 panels2 클릭 → panels2 재클릭 | OK |
| @propval(true): onpanelunload -> onpanelload -> onclick 순서 | (2) "위 동작 시 onpanelunload -> onpanelload -> onclick 순서로 이벤트가 발생합니다." | target1_onpanelunload / target1_onpanelload / target1_onclick 핸들러에서 순서대로 setReturnValue 누적 출력 | OK |
| @spec: enterKeyPanelToggle=false 면 accessibility=true 여도 Enter 토글 불가 | (3) "enterKeyPanelToggle=false 이면 accessibility=true 여도 Enter 키로 패널을 토글할 수 없습니다." | con_accessibility=true × con_enterKeyPanelToggle=false → btn_focusTitle1 후 Enter (열리지 않음) | OK |
| @spec: disabledPanels=true 패널은 accessibility 무관 열기/닫기 차단 | (4) "disabledPanels=true 인 패널에서는 accessibility 속성값과 관계없이 패널 열기/닫기 차단됩니다." | panels3 (disabledPanels=true) → btn_clickDisabledPanel 후 aria-expanded=false 유지 | OK |

- [x] @spec 2개 항목 모두 별도 validation
- [x] 관련 이벤트(onclick/onpanelload/onpanelunload) 핸들러에서 panelID/userID/panel/open 출력 (이벤트 e 객체 개별 속성 검증 아님)

## accordion_P_collapseAll_1.xml

| API 가이드 항목 | 샘플 validation | 케이스 | 상태 |
|---------------|---------------|------|------|
| @description: 초기 렌더링 시 모든 패널을 닫힌 상태로 시작할지 설정 | description 영역에 반영 | - | OK |
| @description: collapseAll=true 이면 unCollapseAll, selectedPanel 무시 | (2) "collapseAll=true 이면 unCollapseAll 속성은 무시되어 패널이 모두 열리지 않습니다." / (3) "collapseAll=true 이면 selectedPanel 속성은 무시되어 지정한 패널이 열리지 않습니다." | con_collapseAll=true × con_unCollapseAll=true / con_selectedPanel=panels2 → btn_getOpenPanel (모두 닫힘) | OK |
| @propval(true): 초기 렌더링 시 모든 패널을 닫힌 상태로 렌더링 | (1) "collapseAll=true 설정 시 초기 렌더링에서 모든 패널이 닫힌 상태로 렌더링됩니다." | con_collapseAll=true → btn_getOpenPanel (getOpenPanelInfo 빈 결과, 전체 aria-expanded=false) | OK |

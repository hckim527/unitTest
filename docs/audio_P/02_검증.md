### 실측이 가이드 문구와 다른 지점 (사실 기재)

- `@description` 의 "Chrome 등 대부분의 최신 브라우저는 자동 재생을 기본적으로 차단합니다" / `@spec` 의 "차단될 수 있습니다" 는 **MCP 자동화 브라우저(Playwright Chromium)에서는 성립하지 않았다.**
  - 자동화 Chromium 은 autoplay policy 가 완화되어 있어 `autoplay="autoplay"` / `autoplay=""` 둘 다 **음소거 없이 실제 재생**되었다(`play` 이벤트 발생, `currentTime=2`, `ended=true`).
  - 즉 이 샘플에서 `자동 재생 차단 여부 : false` 는 자동화 환경 특성이며, 일반 사용자 Chrome 에서 열면 `자동 재생된 개수 : 0` / `차단 여부 : true` 로 뒤집힌다. 출력값을 고정 기대값으로 삼지 말 것(TSQA 작성 시 주의).
  - `navigator.getAutoplayPolicy('mediaelement')` 는 이 자동화 Chromium 에서 **미지원**(함수 없음)이라 `(해당 API 미지원 브라우저)` 로 출력된다. 실제 Chrome 111+ 에서는 `allowed` / `allowed-muted` / `disallowed` 가 출력된다.
- 나머지 항목(속성 전달, 속성명 정의만으로 설정, 속성 제거 시 해제)은 가이드 문구와 **완전 일치**.

### 구성 방식 (사유)

- **배포 엔진 R1641 에 `audio` uiplugin 이 없다.** 엔진 번들 `wbd_R1641_babel_main.js` 전문에 `audio` 문자열 0회(`video` 도 0회 / 대조군 `group` 1837회, `section` 3회). 따라서 `$p.dynamicCreate` 로 audio 컴포넌트를 만들 수 없다.
- `UT_01_생성.md` §7 정적 컴포넌트 배치 규칙 적용 — `wf_body_sample` wframe 을 쓰지 않고 `grp_sample > grp_comp` 를 직접 배치하고 `<audio>` 3개를 정적 선언. `comp_init` / `Target 재생성` 버튼 불필요.
- `@option [autoplay]` 이지만 `@dynamic N` + 정적 배치라 `con_` 셀렉트박스 재생성 방식이 성립하지 않는다 → **값이 다른 audio 3개를 정적 배치해 대비**(autoplay="autoplay" / autoplay="" / 속성 없음).
- `controls` 는 audio 요소를 화면에 표시하기 위한 **전제 설정**이며 검증 대상이 아니다(`@related` 인 controls/loop/muted/preload 에 대한 validation·검증 버튼은 생성하지 않음).
- `cm/gcc/common.xml` / `websquare/config.xml` 무수정.

### 실측이 가이드 문구와 다른 지점 (사실 기재)

- `@spec` 1 "컴포넌트 정의 시 필수 속성으로 함께 정의되므로 기본 재생 컨트롤은 항상 Audio 컴포넌트에 표시됩니다" 는 **엔진이 강제하는 동작이 아니다.**

  - 즉 "항상 표시된다"는 **Studio 에서 컴포넌트를 정의하면 `controls` 가 필수 속성으로 함께 찍히기 때문**(`@necessary Y`)이지, 속성이 없어도 표시된다는 뜻이 아니다. 실측은 `@spec` 1 의 문자 그대로의 해석과 불일치하며, 전제(필수 속성 정의) 하에서만 성립한다.
- `@propval` / `@spec` 2 는 실측과 완전 일치.

### 구성 방식 (사유)

- 배포 엔진 R1641 에 `audio` uiplugin 없음 → `$p.dynamicCreate` 불가, `UT_01_생성.md` §7 정적 배치(`wf_body_sample` 미사용, `grp_sample > grp_comp` 직접 배치, `comp_init` / `Target 재생성` 버튼 없음).

- 컨트롤 표시 여부를 DOM 한 속성으로 단정하지 않고 **속성값 + 프로퍼티 + `getBoundingClientRect()` 렌더 영역** 3종을 함께 출력해 입증.
- `cm/gcc/common.xml` / `websquare/config.xml` 무수정.

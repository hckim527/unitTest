### 구성 방식 (정적 배치 확정 근거)

- 배포 엔진(R1641)에 `section` uiplugin 미탑재. 엔진 번들 내 `section` 문자열은 `WebSquare.uiplugin.group.html5={article:"div",aside:"div",section:"div",...}` 뿐이며, 이는 `group.toHTML()` 의 **IE6/7/8 전용 tagname 폴백표**로 지원 근거가 아님. `controlFactory.createControlHash` 에도 항목 없음.
  - ※ `_websquare_/uiplugin/` 폴더 목록은 지연 로딩 플러그인만 담으므로(span/button/input 도 없음) 미탑재 판단 근거가 되지 않는다.
- `$p.dynamicCreate` 사용 불가 (동일 계열 `article`/`aside` 로 실측 확정):
  - `dynamicCreate(id,"section",'<section…>',parent)` → `Cannot read properties of undefined (reading 'then') at d.createControl`. XML 문자열을 주면 2번째 인자 pluginName 은 무시되고 노드 localName 으로 플러그인이 결정됨.
  - config `/WebSquare/dynamicCreate/parseChild/@value="true"` 강제 → `t.appendTo is not a function` 로 여전히 실패.
  - `dynamicCreate(id,"group",'<xf:group tagname="section">')` → 렌더는 되나 `class="w2group "` 기본 클래스가 붙어 본 API 의 `@spec`(기본 클래스 미추가)과 정면 배치 → 부적합.
- 정적 `<section>` 은 raw HTML pass-through 로 렌더되어 class/id 동작이 가이드와 일치 → DOM(`document.querySelector`) 기준 검증 유효.
- 따라서 UT_01 §7 정적 컴포넌트 배치 규칙 적용 (`wf_body_sample` 삭제, `grp_sample > grp_comp` 직접 배치, `comp_init`/`Target 재생성` 버튼 없음).
- `cm/gcc/common.xml`, `websquare/config.xml` 무수정. class 검증용 CSS 는 공용 `css/tc.css` 의 `.oddClass` / `.evenClass` 재사용(샘플 자체 style 블럭 없음).

### 구성 방식 (정적 배치 확정 근거)

- 배포 엔진(R1641)에 `section` uiplugin 미탑재. 엔진 번들 내 해당 문자열은 `WebSquare.uiplugin.group.html5={article:"div",aside:"div",section:"div",...}` 뿐이며, 이는 `group.toHTML()` 의 **IE6/7/8 전용 tagname 폴백표**로 지원 근거가 아님. `controlFactory.createControlHash` 에도 미등록.
  - ※ `_websquare_/uiplugin/` 폴더 목록은 지연 로딩 플러그인만 담으므로(span/button/input 도 없음) 미탑재 판단 근거가 되지 않는다.
- `$p.dynamicCreate` 사용 불가 (동일 계열 `article`/`aside` 로 실측 확정):
  - `dynamicCreate(id,"section",'<section…>',parent)` → `Cannot read properties of undefined (reading 'then') at d.createControl`. XML 문자열을 주면 2번째 인자 pluginName 은 무시되고 노드 localName 으로 플러그인이 결정됨.
  - config `/WebSquare/dynamicCreate/parseChild/@value="true"` 강제 → `t.appendTo is not a function` 로 여전히 실패.
  - `dynamicCreate(id,"group",'<xf:group tagname="section">')` → 렌더는 되나 `class="w2group "` 기본 클래스가 붙어 부적합.
- 동적 생성 컴포넌트에는 원래 `mf_` 접두사가 붙지 않으므로, `@spec`(Scope 미적용) 입증은 **정적 선언끼리 대비**(section 정적 vs `w2:button` 정적 → `mf_btn_getId`) 해야만 가능 → 정적 배치로 확정.
- 따라서 UT_01 §7 정적 컴포넌트 배치 규칙 적용 (`wf_body_sample` 삭제, `grp_sample > grp_comp` 직접 배치, `comp_init`/`Target 재생성` 버튼 없음).
- `cm/gcc/common.xml`, `websquare/config.xml` 무수정.

### 실측 특이사항

- `@spec` 의 예약어 오류는 **이번 실측에서 미발생**(오류 0건, id=`style` 정상 렌더). section 은 raw HTML pass-through 라 WebSquare 컴포넌트 레지스트리를 거치지 않으므로 예약어 충돌이 발생하지 않는 것으로 보인다. 가이드 원문이 "발생할 수 있습니다"(가능성)이므로 스펙 위반으로 판정하지 않고, 오류 건수 출력으로 확인 가능하도록만 구성했다.
- `@spec` "스크립트 접근 시 ID 필수" 는 section 이 컴포넌트 객체가 아닌 raw DOM 이므로 DOM 조회로 입증. id 미설정본은 `wq_uuid_NN` 형태의 예측 불가 id 가 부여되어 사전 지정 id 로 접근 불가.

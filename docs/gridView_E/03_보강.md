## 결론 / 특이사항
- **result 하위 표시 옵션 6종 미전달** : 엔진의 모든 ongroupby 발화 지점(`layoutController.js` 2891/8349/8369)이 `options` 를 `{sortIndex, sortOrder(, filter)}` 로만 새로 구성해 넘긴다. hideHeader/hideFooter/groupbyHeader/groupbyFooter/closeGroup/showOnlyLastDepth 는 **어떤 조건에서도 전달되지 않음**(MCP 실측 전 케이스 `undefined`). 가이드 @spec1 의 "생략되거나 달라질 수 있습니다" 로 형식상 커버되므로 결함 단정은 보류하되, @param 기술과 실제 전달값의 괴리로 기록. 샘플은 (a) 전달값 출력 (b) par 로 옵션 설정 후 groupby(result) 적용 두 축으로 검증.
- **@spec3 "제거" 조건 미발생(결함 의심)** : GroupBy Zone 칩의 X 아이콘 → `handleGroupbyZoneClick` → `ungroupColumn()` 경로에 `fireEvent("ongroupby")` 가 없어 Group Column 이 제거돼도 이벤트 미발생. 또한 칩을 Zone 밖으로 Drag&Drop 하는 제거 동작 자체가 미지원(상태 무변화).
- **@spec3 "선택 컬럼 그룹 해제" 미발생(결함 의심)** : 컨텍스트 메뉴 ungroupMsg 분기(`layoutController.js:8320`)도 `ungroupColumn()` 만 호출하고 fireEvent 없음. "선택 컬럼 그룹"(groupMsg) 은 정상 발생 확인.
- 컨텍스트 메뉴는 **Group Header Row 위에서 우클릭하면 colIndex=-1 로 처리되어 그룹 메뉴가 동작하지 않음** → 검증은 Header 우클릭(useHeaderContextMenu=true) 또는 실제 데이터 Cell 우클릭으로 수행해야 함.
- GroupBy Zone Drag&Drop 은 `mousedown(header) → mousemove(zone) → mouseup(zone)` 단일 점프 실제 마우스 이벤트로 재현 가능(뷰포트 1600x1200).

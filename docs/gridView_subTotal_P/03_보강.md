### 재사용 정보 — SubTotal 전제 구성 / DOM 선택자 / 삽입 규칙
- **최소 전제 구성** : `<w2:gridView dataList="data:dlt_bind">` 안에 `<w2:header>` + `<w2:gBody>` + `<w2:subTotal targetColumnID="{Body Column ID}">`.
  `w2:subTotal` 하위는 `<w2:row><w2:column .../></w2:row>` 이며 Body 와 같은 컬럼 수를 채워야 한다.
  소계값은 `inputType="expression" expression="sum('amount')"` Cell 로 만든다.
- **삽입 규칙** (`subtotalDataController.drawSubtotalRow`)
  - `subtotalTableList` 는 **targetColumnID 를 key** 로 하는 해시 → 같은 targetColumnID 로 SubTotal 을 2개 정의하면 서로 덮어쓴다.
  - 각 데이터 rowIndex 마다 `dataList._getCellData(rowIndex, targetID) != _getCellData(rowIndex+1, targetID)` 이면 그 Row 뒤에 SubTotal Row 를 노출.
    마지막 Row 는 항상 경계로 처리(`nextValue = nowValue + "_12"`)되므로 마지막에는 반드시 1개가 삽입된다.
  - 존재하지 않는 ID/미설정이면 모든 Row 의 조회값이 undefined 로 같아져 마지막 1개만 노출 → 전체 한 그룹.
  - 여러 SubTotal 이 같은 Row 에서 겹치면 `for (targetID in subtotalTableList)` 순회 = **선언(정의) 순서**대로 출력된다.
- **DOM 선택자**
  - Body Table : `table#{gridId}_body_table` — **thead(헤더 tr) + tbody** 구조이므로 행 수집은 `tbody > tr` 로 한정
  - 데이터 Row : `tr[data-tr-id="{gBody row id}"].grid_body_row` (여분 filler 는 `.w2grid_hidedRow` + display:none)
  - SubTotal Row : `tr[data-subtotal="{targetColumnID}_{subTotal 내 row 순번}"]`, `tr[data-targetcolumnid="{targetColumnID}"]`
    - 표시된 것만 `data-subtotalrowindex="{직전 데이터 rowIndex}"` 를 갖는다 → 삽입 위치 판정에 사용
    - 선언한 `<w2:row>` id 는 유지되나 클론마다 중복되어 고유 식별자로 못 쓴다
    - targetColumnID 미설정 시 두 data 속성 모두 문자열 `undefined`
  - 숨김 클론이 데이터 Row 사이에 미리 깔려 있으므로 `getComputedStyle(tr).display !== "none"` 필터 필수
- **주의** : Grid height 가 작으면 뒤쪽 행이 렌더되지 않아 실측이 잘린다(640x420 기준 10행). 데이터 행 + 삽입될 SubTotal 행 총합이 모두 보이도록 height 를 잡을 것(본 샘플 700px, 최대 16행).

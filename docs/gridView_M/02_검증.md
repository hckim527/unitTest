<details><summary>철회된 원 기록 (보존용)</summary>

`inputType="textImage"` + **`viewType="text"`** 컬럼(idx3 `ntxt`)에서:
- `setCellImageSrc(...)` → **true 반환**
- `getCellImageSrc(...)` → **`/img/png.png` 정상 반환**
- 그러나 화면에는 **`img` 요소가 생성되지 않음**

엔진은 두 메소드 모두 **`viewType` 을 전혀 검사하지 않고 `inputType` 만 확인**한다. 따라서 가이드 @spec3 "Column 의 inputType='textImage', viewType='icon' 인 경우에 Body Cell 의 유효한 imageSrc 속성값을 반환해야 합니다" 는 **반환값 기준으로는 성립하지 않고, 화면 표시 기준으로만 성립**한다.
→ 가이드 문구 수정 또는 엔진 보완 중 어느 쪽인지 **판단 대기 중**. 샘플은 현재 동작(반환 O / 표시 X)을 그대로 출력하도록 구성.

</details>

**철회 사유**

> @spec3 `"Column 의 inputType='textImage', viewType='icon' 인 경우에 Body Cell 의 유효한 imageSrc 속성값을 반환합니다."` 는 **긍정 조건 서술**이며, `viewType` 이 `icon` 이 아닐 때의 동작은 가이드가 규정하지 않았다. 규정되지 않은 조건에서의 동작을 근거로 결함을 주장한 것이므로 성립하지 않는다. UT_01 §2 의 "가이드에 명시되지 않은 유효성 임의 추가 금지" 에도 어긋난다. Jira fail_ 샘플 등록 제안도 함께 철회.

→ 이에 따라 @spec3 검증 구성은 `viewType="text"` 부정 검증에서 **`viewType="icon"` 긍정 검증**으로 교체되었다(아래 `_1.xml` 구성 변경 이력 참조).

2차 수정에서 `optionParam` 을 `trim` 과 묶어 "4~5번까지 수행" 으로 뒀으나 **부정확했다.**

`optionParam` 은 **업로드 결과가 미설정/설정 양쪽 동일하다** (실측 표에도 둘 다 `"  csvA1  "`). 가이드상 이 값은 DRM 연계 시 **사용자 정의 Class 로 전달되는 값**이라, 그 Class 가 없는 환경에서는 그리드 결과에 아무 영향이 없다. 즉 **4~5번을 수행해도 검증되는 것이 없다.**

절차 4·5 의 괄호 표기를 `(trim 확인 시)` 로 바꾸고, 확인 항목에 `optionParam` 전용 줄을 추가했다:

> - optionParam 은 3번 출력의 전달값으로만 확인한다 - 미설정 시 optionParam : [] / 설정 시 optionParam : [optionParamTest] 로 대비되고, 전송 파라미터의 키 이름이 optionParam 인 것으로 서버에서 참조되는 키를 확인 (4~5번은 수행하지 않음)
> - trim 은 4~5번까지 수행하여 업로드 결과로 확인한다

**MCP 실측 — `optionParam` 3번 출력 대비 및 전송 키 근거**

| `par_optionParam` | 결과창 출력 | hidden input (`name` / `value`) |
|---|---|---|
| 미설정 | `optionParam : []` | `name="optionParam"` / `value=""` |
| `optionParamTest` | `optionParam : [optionParamTest]` | `name="optionParam"` / `value="optionParamTest"` |

hidden input 의 실제 속성은 `name="optionParam"`, `id="mf_mf_target1_csvPop_wframe_optionParam"`, `type="hidden"` 이다.

이 대비가 validation 3건의 확인 수단이 된다:

| validation | 확인 수단 |
|---|---|
| "전달할 값을 설정합니다" | 설정 시 출력이 `[optionParamTest]` 로 바뀜 |
| "서버에서 `optionParam` 키로 참조됩니다" | 전송 파라미터의 **키 이름이 `optionParam`** (hidden input `name` 속성) |
| "생략하면 기본값인 빈 문자열" | 미설정 시 출력이 `[]` (hidden `value=""`) |

**한계 명시** — "서버에서 참조된다" 는 것 중 **서버 측 참조 동작 자체는 DRM 사용자 정의 Class 없이 확인할 수 없다.** 이 샘플은 **클라이언트가 그 키 이름으로 값을 실어 보낸다는 사실까지만** 검증한다. 그 이상은 이 환경에서 검증 불가이며, 무리하게 그리드 결과로 판정하려 하면 미설정/설정이 같은 결과라 오히려 잘못된 결론이 난다.

`trim` 만 로컬 경로에서 업로드 결과로 검증되므로 **4~5번은 `trim` 전용**이다.

MCP 실측으로 두 경우의 출력 URL 확인 완료:

| `par_msaName` | 결과창 출력 |
|---|---|
| 미설정 | `msaName : []` / `업로드 요청 URL : /websquare/csvToXML.wq` |
| `msa_server` | `msaName : [msa_server]` / `업로드 요청 URL : http://192.168.100.250:8080/csvToXML.wq` |

**MSA 서버 경로가 자동 추가되는 것이 출력에 그대로 보이므로 이것으로 검증이 성립한다** — 그리드 데이터 반영 여부로 판정하지 않는다.
validation 10건·par 컨트롤·픽스처는 불변이다.

### 구성 방식 (참조 샘플과 다른 점 / 사유)

- **canvas 는 현재 배포 엔진(R1641)에 uiplugin 이 등록되어 있지 않다.** (아래 "엔진 제약" 참조) → `$p.dynamicCreate(id, "canvas", ...)` 불가, 컴포넌트 객체·메소드 미생성.
- 따라서 `UT_01_생성.md` §7 "정적 컴포넌트 배치 규칙" 을 적용하여 `wf_body_sample` 대신 `grp_sample > grp_comp` 를 직접 배치하고 `<canvas>` 를 정적으로 두었다. (`comp_init` / `Target 재생성` 버튼 불필요)
- `class` 는 `@dynamic N` (렌더 시점 전용) 이므로 con_ 셀렉트박스 + 재생성 방식이 아니어도 검증에 지장 없음. class 설정본(target1) / 미설정본(target2) 2개를 정적 배치해 대비 검증.
- canvas 는 아무것도 그리지 않으면 투명한 빈 영역이라 화면에서 위치 식별이 어려우므로, 가이드 `@sample` 처럼 인라인 `style` 로 명시적 크기(200x120)와 배경색만 부여했다(표시용 전제, 검증 대상 아님). `.oddClass` 의 border / `.evenClass` 의 border-radius 관찰을 방해하지 않도록 인라인 style 에 border / border-radius 는 넣지 않았다.
- class 검증용 CSS 는 프로젝트 공용 `css/tc.css` 의 `.oddClass{border:1px solid red}` / `.evenClass{border-radius:15px}` 사용 → 샘플 자체 style 블럭 없음.
- `cm/gcc/common.xml`, `websquare/config.xml` 무수정.

### 엔진 제약 (결함 아님 / 미구현)

- 라이브 엔진: R1641. 이 엔진에 `canvas` uiplugin 이 없다.
- ⚠ 번들에 `canvas` 문자열이 243회 나오지만 이는 차트 등 내부 렌더링 용도이며 플러그인 등록이 아니다. **단순 문자열 검색으로 판정 금지.**
  - 정확한 근거: `uiplugin.canvas` 형태 등록 0건 + `controlFactory.createControlHash` 에 `canvas` 항목 없음(해시 원문: script/label/value/choices/item/itemset/tab/tabs/mainMenu/childMenu/node/attributes/switch/case/contents/content/autoFinder/panelContent).
  - `_websquare_/uiplugin/` 폴더 목록 유무는 판정 근거가 아니다.
- `<canvas>` 태그는 컴포넌트가 아니라 **raw HTML 마크업으로 통과(pass-through)** 되어 렌더된다. class/id 동작은 API 가이드 `@spec` 과 일치하지만 컴포넌트 객체·메소드는 존재하지 않는다.
- `$p.dynamicCreate` 3경로 모두 부적합(기확정, 재시도 금지)
  - `dynamicCreate(id,"canvas",XML,…)` : XML 문자열을 주면 pluginName 이 무시되고 노드 localName 으로 결정되어 실패
  - config `parseChild="true"` 강제 : `t.appendTo is not a function`
  - `group + tagname="canvas"` : `w2group` 기본 클래스가 붙어 본 API 의 `@spec` 과 정면으로 어긋나 부적합

### 발견 이슈 / 제약
- 배포 엔진(R1641)에 `canvas` uiplugin 미등록 → `$p.dynamicCreate("...", "canvas", ...)` 불가. 정적 `<canvas>` 는 raw HTML pass-through 로 처리되어 `mf_` 접두사·엔진 기본 클래스가 붙지 않고 WebSquare 컴포넌트 객체/메소드도 없음 (DOM 표준 API 만 사용 가능). → 결함이 아니라 미지원 컴포넌트 특성
- 예약어(`style`) id 설정 시 오류 미발생 (JS 오류 0건). 가이드가 "오류가 발생할 수 **있습니다**"(가능성) 표현이므로 위배 아님. audio / video / HTML5 시맨틱 계열 실측과 동일

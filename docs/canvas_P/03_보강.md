### 구성 메모

- `UT_01_생성.md` §7 정적 배치 — `wf_body_sample` 미사용, `grp_sample > grp_comp` 직접 배치. `comp_init` / Target 재생성 버튼 없음.
- 배포 엔진(R1641)에 `canvas` uiplugin 미등록(`uiplugin.canvas` 0건, `controlFactory.createControlHash` 미포함) → `$p.dynamicCreate` 불가, 정적 `<canvas>` raw HTML pass-through 로만 구성. WebSquare 컴포넌트 객체/메소드 없음(DOM 표준 API 만 사용 가능).
- `<canvas>` 는 아무것도 그리지 않으면 투명 → 표시용으로 `width:200px;height:120px;background-color:#f0f0f0;` 만 공통 지정(검증 대상 아님).
- `@spec` 2(Scope 미적용) 입증은 **정적 선언끼리** 대비(canvas `target1` vs 정적 button `mf_btn_getId`). 동적 생성 컴포넌트는 원래 `mf_` 가 붙지 않아 대비 근거가 되지 못함.
